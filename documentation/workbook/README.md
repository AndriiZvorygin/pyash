# Documentation Workbooks

This directory holds active, structured working documents such as vocabulary
curation worksheets and agent workflow guides. A workbook records work in
progress and practical handoffs; it is not itself a specification or a
published runtime data volume.

Keep proposals under `documentation/suggest/`. Move a workbook's settled
contracts into the relevant reference/specification and keep only active
curation work here.

- [Pyash GPU Housekeeper](pyash-gpu-housekeeper.md) — text futures, image
  generation, handles, and worker setup.
