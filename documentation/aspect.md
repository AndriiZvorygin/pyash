| Pyash aspect           | Human-language meaning                                              | Common expression patterns                                | Best programming analogue                                                            |
| ---------------------- | ------------------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Perfective (`fa`)      | Whole event as a single bounded unit                                | Slavic perfective stems; simple past style                | Synchronous call that runs to completion and returns a value                         |
| Imperfective (`me`)    | Event viewed “from inside”: ongoing, repeated, background           | Imperfect tense; imperfective stems; context-driven       | Ongoing operation or stateful process, result may be partial or evolving             |
| Retrospective (`tyih`) | “Looking back” from a reference point, often with current relevance | Perfect-like constructions (“have done”), relative past   | `await` a promise, then use the resolved result                                      |
| Progressive (`pfih`)   | Action in progress                                                  | “be + -ing”, auxiliaries, aspect markers                  | Start async work, return a promise or future immediately                             |
| Semelfactive (`swah`)  | Single brief “one-shot” event                                       | Lexical verbs like “blink/knock”; derivational morphology | One-shot event emission or a single callback invocation                              |
| Prospective (`rwah`)   | Event about to happen, later than reference time                    | “going to”, “about to”, future-marking                    | Schedule a task, return a handle, timer, or promise for future start                 |
| Gnomic (`go`)          | General truth, lawlike statement                                    | Generic present, proverb-like forms                       | Pure function, invariant rule, constant definition                                   |
| Inchoative (`za`)      | Begin a state, enter a condition                                    | “become/get X”, inchoative affixes                        | Initialise, start a service, transition state `INIT -> RUNNING`                      |
| Completive (`mweh`)    | Bring action fully to completion                                    | “finish completely”, completive markers                   | `commit()`, `flush()`, finalize, close a stream cleanly                              |
| Cessative (`qa`)       | Stop doing, cease a state                                           | “stop/quit”, cessative markers                            | Cancel, abort, stop a worker, signal shutdown                                        |
| Delimitative (`dweh`)  | Do for a while, bounded duration                                    | “for a bit”, delimitative markers                         | Timeboxed run, timeout wrapper, “run for N ms then stop”                             |
| Telic (`tfeh`)         | Has an inherent endpoint or goal                                    | Often encoded via object and framing                      | Goal-driven job: completes when a condition is met                                   |
| Atelic (`lyeh`)        | No inherent endpoint, open-ended activity                           | Activities like “run”, “sleep”                            | Long-running loop, stream processing, daemon-like task                               |
| Momentane (`mreh`)     | Instantaneous, punctual viewpoint                                   | Punctual aspect markers, lexical class                    | Atomic operation, single instruction-like step                                       |
| Habitual (`xi`)        | Regular customary action                                            | Habitual markers; “used to”; generic present              | Cron job, periodic task, scheduled retry policy                                      |
| Continuative (`ta2`)   | Still ongoing, continues to hold                                    | “still”, continuative markers                             | Keepalive state, idempotent “still running” check, `await` on a never-ending promise |
| Frequentative (`ra2`)  | Repeated often, high frequency                                      | Frequentative morphology; adverbs like “often”            | Polling loop, repeated events, batch of repeated calls with backoff control          |
