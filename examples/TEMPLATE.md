# Example Template

- **id**: unique slug (e.g., `plus-sum-basic`)
- **status**: draft | ready | regression | archived
- **intent**: brief purpose of the example (what it demonstrates or reproduces)
- **type**: REPL | test | doc — choose REPL for interactive transcripts, test for runnable snippets, doc for explanatory notes
- **REPL input**: exact lines to run (for REPL examples) or command snippet (for test examples). Prefer real, test-backed transcripts; no fabrication when unknown. Use speakable names (no underscores) for ceremonies/verbs.
- **Expected output**: what the REPL prints or what the test should assert. Fill when derived from passing tests or confirmed behaviour; leave TODO if uncertain rather than inventing.
- **Notes**: optional context, links to related tests/issues, setup caveats
