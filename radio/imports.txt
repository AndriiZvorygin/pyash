# not. The title is optional too: it is the name the house gave the song, and

# contract, so the station reads the engine and the topic off the name the way

# own voice.

# The import copies the song into radio/audio/ as an mp3 the station can
# stream, writes its title into the tag of the file, and copies the sheet into
# radio/lyrics/ so the station page can show the words. A song that is already
# in the catalogue is left alone, apart from its title, which is written if the
# song does not carry it yet.
